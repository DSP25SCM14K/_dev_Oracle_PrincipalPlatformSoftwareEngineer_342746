# Dev Kumar — Oracle platform software portfolio

Responsive static portfolio focused on platform software, middleware interoperability, API lifecycle, observability, and developer adoption. The hero uses a generated cloud platform architecture background with subtle drift; the interactive SVG flow shows how a shared runtime and versioned API move through compatibility testing, safe rollout, and team adoption.

## Files

- `index.html` — portfolio with all 15 resume experience bullets, 23 user-listed projects, and profile links
- `styles.css` — responsive layout, motion, and visual system
- `script.js` — rotating focus text, interactive API lifecycle diagram, scroll reveals, and project filters
- `platform-architecture.jpg` — generated hero background image
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow
- `ROLE_RESEARCH.md` — analysis of job 342746 and Oracle/OCI context with sources

Each of the 23 projects listed by the user has a `SourceCode` link. `Technical Demo` appears only for TradeSentinel, AskMyStore, Strangers, and Oxide-HV, which have demo URLs in the request. The IEEE paper and certificate are linked by their own labels. The site omits LinkedIn and has no footer.
